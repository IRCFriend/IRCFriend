IRCFriend privacy

Privacy by Design

IRCFriend is built to connect you with IRC servers and communities without adding a separate social profile, advertising layer, or chat-history service. This page describes the app’s current behavior while it remains in development.

01

What IRCFriend handles

When you connect, IRCFriend handles the server address, port, nickname, username, real name, room names, messages, and other IRC information needed for the connection and features you choose to use.

That information is sent to the IRC server and other IRC users as required by the conversation. IRCFriend does not own or control those servers, rooms, or messages.

02

What it does not add

The current app does not include an IRCFriend account, advertising, built-in analytics, or telemetry. It does not send chat activity to an IRCFriend tracking service, and it does not provide cloud chat-history sync.

This description will be updated before release if the app’s services or data practices change.

03

What stays on your Mac

Preferences such as chat text size, theme, sound settings, remembered connection settings, and a chosen DCC save-folder permission are stored locally on your Mac so the app can work as you configured it.

Active room members, messages, private-message content, and transfer status are held for the current session. IRCFriend does not save chat logs or private-message history by default.

04

Connections and TLS

IRCFriend supports Transport Layer Security (TLS) connections and verifies server certificates by default. TLS encrypts the connection between the app and the IRC server while it is in use.

TLS is not end-to-end encryption for IRC messages. The IRC server, room operators, and message recipients may be able to see, retain, or disclose messages. The option to allow an invalid certificate is intended only for deliberate testing of a trusted server.

05

Files and DCC

DCC transfers are separate from the IRC conversation and may not have the same TLS protection. IRCFriend requires explicit acceptance before receiving a file, sanitizes the received filename, and does not open downloaded files automatically by default.

Accepted files are written to the folder you choose on your Mac. Review unexpected files with appropriate security tools before opening them.

06

This website

The IRCFriend information site is hosted with GitHub Pages. GitHub may process technical information about website visits for hosting, security, and service operation. See GitHub’s Privacy Statement for GitHub’s current practices.

If you contact us, we receive the information you choose to include in your message. We will publish the support contact details before release.

This page describes the current development version of IRCFriend. We’ll update it if the app’s information practices change.

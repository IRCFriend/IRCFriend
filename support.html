Privacy policy · Last updated August 11, 2026

Privacy policy

IRCFriend is designed to connect directly to IRC servers chosen by the user. IRCFriend does not use advertising, analytics, user accounts, or telemetry in the current release.

Information handled by IRCFriend

To provide IRC functionality, the app may handle server addresses, connection settings, usernames or nicknames, chat messages, room information, and files transferred through IRC. This information is sent to the IRC servers and other users selected by the user, as necessary to provide the requested connection.

Local information

IRCFriend keeps active chat, room, people, private-message, and transfer information in memory for the current session. It does not save chat logs or private-message history. If the user chooses to remember a connection, IRCFriend stores selected connection details and preferences locally on the Mac. IRCFriend does not collect or store passwords through its website or a remote account.

Files and downloads

Files received through DCC are saved only after the user explicitly accepts the transfer and chooses a location. The user controls those files using macOS Finder and can delete them at any time.

Website hosting

This website is hosted using GitHub Pages. GitHub may process technical information, including visitor IP addresses, for security and service operation. Please see GitHub’s Privacy Statement for information about GitHub’s handling of website visits.
